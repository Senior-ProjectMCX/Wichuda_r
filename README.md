# Model B: Digital Twin-inspired DCS Phantom

**Senior Project 492 | Computer Engineering, Chiang Mai University (2026)**

This repository contains **Model B**, a Python-based, MCX-driven two-layer phantom simulation for Diffuse Correlation Spectroscopy (DCS). It simulates detected-photon paths and calculates DCS correlation signals for comparison with a physical phantom reference dataset.

Related repositories: [Model A](https://github.com/Senior-ProjectMCX/wachirawit.chai) | [Core: reference data and research papers](https://github.com/Senior-ProjectMCX/core)

## 2. Model parameters

| Parameter | Model B |
|---|---|
| Geometry | 100 × 50 × 40.5 mm; shallow layer 5.5 mm, deep layer 35 mm |
| Source–detector separation (SDS) | 10, 20, 30 mm |
| Launched photons | 10⁷ |
| Optical properties | μa = 0.56 cm⁻¹; μs′ = 4.81 cm⁻¹; g = 0.89; n = 1.37; λ = 785 nm |
| Flow mapping | αD_B = FR × 0.4 × 10⁻⁶ mm²/s |
| Partial pathlength | mm (0.5 mm/voxel) |
| β | Reference g₂(0) − 1 |

See `dcs_simulator/parameters.py` for additional configuration details. The flow coefficient was selected through manual tuning.

## 3. Installation

The simulation requires Python, the dependencies below, and a compatible GPU/MCX environment for new photon simulations. The project was developed using Python 3.13.

From the repository root in PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r .\dcs_simulator\requirements-ui.txt
```

## 4. Running the simulation

From the repository root:

```powershell
# Check model parameters and DCS processing equations
python .\dcs_simulator\parameters.py
python .\dcs_simulator\dcs_processor.py

# Check MCX configuration without launching photons
python .\dcs_simulator\simulation.py --dry-run

# Run a photon simulation (requires a compatible GPU)
python .\dcs_simulator\simulation.py --name trial_01 --nphoton 10000000
```

The simulation exports detected-photon data and metadata to `dcs_simulator/output/`. Choose a new `--name` for each run to avoid overwriting existing results.

## 5. Dataset generation and evaluation

```powershell
python .\dcs_simulator\dataset_generator.py
python .\dcs_simulator\evaluation.py
python .\dcs_simulator\evaluation_analysis.py
```

These scripts use the available reference data and stored simulation outputs; running them may regenerate output files. Additional analysis and verification scripts are available in `dcs_simulator/`.

### Final evaluation results

The final project comparison evaluated **132 flow conditions** (excluding `(0,0)`), using **5 selected physical-phantom trials per condition** (660 trials) at **3 source–detector separations (SDS)**, for a total of **1,980 g₂ correlation curves**. For each condition, the selected trials had measured flow rates closest to the preset flow rates (K = 5).

The results below are **Model B metrics from the common final A/B evaluation**, after converting detected-photon partial pathlengths from voxel units to millimeters (0.5 mm per voxel). They are **not** the separate exploratory results generated by `dcs_simulator/evaluation.py`.

| Metric | SDS 1 cm | SDS 2 cm | SDS 3 cm |
| --- | ---: | ---: | ---: |
| R² median (per trial) | 0.691 | 0.552 | 0.516 |
| R² mean | -0.04 | 0.49 | 0.55 |
| Pooled RMSE of g₂ | 0.088 | 0.072 | 0.060 |
| BFI-X ratio median / mean | 2.04 / 1.74 | 2.98 / 2.56 | 3.56 / 3.14 |
| BFI-Y ratio median / mean | 3.82 / 3.30 | 2.60 / 2.24 | 1.80 / 1.60 |

- **R²** measures agreement between each simulated g₂ curve and its corresponding physical-phantom curve. Higher is better.
- **Pooled RMSE** is calculated across all g₂ points for the evaluated curves at each SDS. Lower is better.
- **BFI-X ratio** compares BFI fitted from simulated and measured g₂ curves using the semi-infinite fitting approach (paper Eq. 3).
- **BFI-Y ratio** compares simulated BFI with the BFI values supplied in the physical-phantom metadata.
- For both BFI ratios, **1.0** indicates agreement; values above 1 indicate a larger simulated BFI under the stated comparison.

The final A/B evaluation uses a **separate common comparison procedure**. The scripts `evaluation.py` and `evaluation_analysis.py` in this repository are used for Model B's own development and diagnostic evaluation, and should not be interpreted as the source of the final A/B comparison metrics above.

The shared [Core repository](https://github.com/Senior-ProjectMCX/core) provides the physical-phantom reference data and related research papers. The final A/B comparison and discussion are presented in Chapter 4 of the project report. This model is intended for simulation and research evaluation, not clinical diagnosis.
